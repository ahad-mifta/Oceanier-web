# OCEANIER WEBSITE REDESIGN — COMPLETE UI/UX MODIFICATION BRIEF

## Project Name

**Oceanier — AI Workforce Platform**

## Objective

Redesign the existing Oceanier website into a premium global AI workforce platform.

The current design direction is visually strong, but the messaging feels like a generic AI automation SaaS.

The redesigned website should communicate:

> **Oceanier gives every business an AI workforce.**

The visitor should immediately understand:

- They don't need developers.
- They don't need to understand APIs.
- They don't need to build workflows manually.
- Oceanier provides ready AI crews and custom AI solutions.

The final experience should feel like:

**Apple + Linear + Relevance AI + Stripe + futuristic ocean command center**

## Core Visual Concept

Oceanier represents:

- A business = Ship
- AI agents = Crew
- Oceanier = The command system controlling the crew

Use:

✓ Depth layers  
✓ Floating cards

✓ Soft particles

✓ Navigation system feeling

❌ Cartoon ships  
❌ Waves everywhere  
❌ Gaming style  
❌ Overly colorful gradients
